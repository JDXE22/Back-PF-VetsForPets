# VetsForPets 🌟🐾🐈

👋¡Bienvenido a **VetsForPets**! Una plataforma moderna y accesible diseñada para conectar a dueños de mascotas 🐕🐱 con veterinarias de confianza 🏥, facilitando el cuidado y la salud de sus animales ✨.

## Descripción General

**VetsForPets** es una aplicación en línea que ofrece diversas funcionalidades esenciales:

- **Registro de Mascotas:** Registra a tus mascotas 🦜 con información detallada sobre su salud, raza, edad y necesidades específicas.
- **Geolocalización de Veterinarias:** Encuentra las veterinarias más cercanas 🏞️ utilizando un mapa interactivo 🌍.
- **Agendamiento de Citas:** Agenda y administra citas con veterinarias de forma rápida y sencilla con solo unos clics 🗓.
- **Botón de Emergencia:** En caso de urgencia, usa nuestro botón de emergencia ⚡ para acceder a ayuda rápida en vivo.
- **Sistema de Recompensas:** Obtén beneficios y descuentos en consultas, vacunas y más por el cuidado continuo de tu mascota 🌟.

## Tecnologías Utilizadas

El desarrollo del proyecto se basó en las siguientes tecnologías:

### Backend:
- **Node.js:** Entorno de ejecución de JavaScript para la capa del servidor.
- **NestJS:** Framework modular para construir aplicaciones escalables y eficientes.
- **TypeScript:** Lenguaje tipado para mayor seguridad y mantenibilidad.
- **PostgreSQL:** Base de datos para gestionar usuarios, mascotas y veterinarias.
- **TypeORM:** ORM para facilitar la gestión y relaciones de datos.
- **Swagger:** Documentación interactiva para la API.
- **WebSockets:** Implementación para chat en vivo en emergencias.
- **JWT & OAuth:** Autenticación segura y gestión de sesiones.

### Frontend:
- **React.js:** Framework de JavaScript para interfaces escalables y responsivas.
- **TypeScript:** Mecanismo tipado para seguridad en el código.
- **CSS & Tailwind CSS:** Lenguaje de estilos y framework para diseños optimizados.
- **WebSockets:** Soporte para chat en tiempo real.
- **Calendar.js:** Gestión de citas y recordatorios.
- **OAuth:** Inicio de sesión con Google para autenticación segura.
